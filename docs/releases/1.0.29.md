# Verso 1.0.29

Verso 1.0.29 adds Claude Opus 5.5 and support for multiple accounts in connected apps, with improvements to sign-in and custom MCP connections.

- Select Claude Opus 5.5 using your Anthropic API key. Your existing default model stays the same.
- Add another account from the connected-app sidebar, review accounts in Settings, and choose the sending account when approving a message draft.
- Route app tools and memory synchronization to the selected account, with separate memory cursors for each account.
- Identify Gmail accounts by their Google profile. Removing a verified duplicate connection preserves the remaining connection’s Google authorization.
- Recover sign-in after sleep or temporary network failures without discarding renewable credentials.
- Configure custom MCP connections that require OAuth client credentials, including HubSpot, and recover from interrupted authorization.
- Manage workspace files and chat attachments, and optionally connect apps through your own Composio project. These features were merged previously but were not included in the 1.0.28 installer.

Requires Apple Silicon and macOS 14 or later. No hosted database migration is required.
